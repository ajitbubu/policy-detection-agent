WHAT CHANGED (plain English)
---------------------------------------------------------------
Prior rule: Under PECR (UK), all non-strictly-necessary cookies and similar technologies required prior consent, with no exemptions beyond the "strictly necessary" category. Maximum penalty was GBP 500,000.

New rule (in force since 2026-02-05, guidance finalized 2026-04-29): The Data Use and Access Act 2025 (DUAA) amended PECR to create five new consent-free categories -- (1) statistical/analytics technologies used solely to improve the service for the operator, (2) appearance/functionality customisation (e.g. accessibility, display preferences), (3) software update delivery, (4) functionality enhancement, and (5) emergency assistance. Analytics and customisation exemptions are not "do nothing" -- they replace consent with two obligations: (a) provide clear and comprehensive information about the purpose, and (b) give users a "simple means of objecting free of charge." The guidance adds a new sub-chapter defining what "simple means of objecting" requires. Maximum PECR penalty is now aligned with UK GDPR: GBP 17.5M or 4% of global annual turnover, whichever is higher. Advertising-related cookies remain fully outside all exemptions.

Why this matters for CMP: UK-jurisdiction consent banners must be updated: analytics/functionality cookies no longer require opt-in consent, but must display an opt-out mechanism and information notice. This is a positive change (less friction) but requires active implementation to avoid continuing to apply the old, overly restrictive consent gate, and to correctly implement the new opt-out.

ID-PRIVACY IMPACT
---------------------------------------------------------------
Affected subsystems:
  [X] Consent Banner               -- UK-jurisdiction banner logic must be updated: for analytics and customisation cookies, replace consent opt-in gate with information notice + opt-out mechanism. "Reject all" button is still required for advertising categories. New sub-chapter on "simple means of objecting" means the opt-out must be persistently accessible (e.g. footer link, not only in banner). Banner layer 1 must surface opt-out for exempt categories as well as accept/reject for non-exempt.
  [X] Cookie Classification ML     -- UK classifier must recognise and tag analytics and customisation cookies that qualify for the DUAA exemption vs. those that do not (e.g. analytics cookies feeding advertising attribution do NOT qualify). New classification label needed: "uk-duaa-analytics-exempt" and "uk-duaa-customisation-exempt" alongside existing "analytics", "functional", "marketing" taxonomy.
  [X] Consent Storage & Proof      -- For exempt categories, consent records are replaced by opt-out records. Schema must support: purpose_legal_basis = "duaa_statistical_exemption" | "duaa_customisation_exemption"; opt_out_timestamp; opt_out_channel. Consent proof is no longer needed for these categories -- but opt-out proof is.
  [ ] Consent Signals (GPC/TCF/GPP)-- No direct change; GPC/DNT opt-out signals should be mapped to the new opt-out right for exempt categories. Verify GPC handling routes correctly for UK users.
  [X] Geo / Jurisdiction Routing   -- UK (GB) ruleset must be updated with the new exemption logic. Ensure the routing table reflects DUAA-amended PECR, not old PECR. Separate GB routing from EU/EEA routing to avoid cross-contamination.
  [ ] Vendor / SDK Governance      -- No new vendor disclosure requirement specific to exempt categories, but vendor records should note DUAA exemption status to avoid incorrect consent gating.
  [ ] DSR Engine                   -- New right to object (for exempt categories) is a PECR opt-out right, not a DSR. It should be surfaced through the CMP opt-out mechanism, not the DSR portal -- no DSR engine change required.
  [X] Audit / Logging              -- Audit logs must record opt-out events for DUAA-exempt categories (previously only consent events were logged). New event type: "pecr_duaa_optout".
  [ ] Cross-border transfer        -- No change.
  [X] Tenant Config / Admin UI     -- New per-tenant UK config: toggle for "analytics DUAA exemption" ON/OFF; configure opt-out mechanism style (footer link, banner toggle, preference centre); disclosure text field for statutory "clear and comprehensive information" notice. Add warning if tenant enables DUAA analytics exemption but lacks an opt-out mechanism pointing to a live preference centre.
  [X] Documentation / DPIA / RoPA  -- RoPA entries for UK analytics cookies must update legal basis from "consent" to "PECR DUAA statistical exemption." DPIAs for UK analytics deployments should be updated.
