WHAT CHANGED (≤4 sentences, plain English)
───────────────────────────────────────────────────────────────
New Zealand's Biometric Processing Privacy Code came into force 2025-11-03 for any new collection of biometric information, but agencies already processing biometrics before that date were given a nine-month grace period — which ends 2026-08-03. After that date, all biometric processing (face geometry, voiceprints, gait, emotion/attention inference) must meet the Code's necessity-and-proportionality test, give individuals a non-biometric alternative where reasonable, and disclose purpose/retention clearly before collection. In March 2026 the OPC issued Amendment No. 1 to the Code to align it with the new Information Privacy Principle 3A (indirect-collection notice), which itself has been operative since 2026-05-01. This is not a cookie-banner change per se, but it directly affects any ID-PRIVACY tenant using biometric-adjacent features (chat-widget face/voice capture, session-replay-style biometric inference) for NZ users.
