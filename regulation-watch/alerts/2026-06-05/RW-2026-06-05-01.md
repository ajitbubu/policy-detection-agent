WHAT CHANGED
---------------------------------------------------------------
The ICO published its final "Storage and Access Technologies" (SAT) guidance on 29 April 2026, replacing all prior cookies guidance. This finalises the ICO's position on three new consent exemptions introduced by the Data (Use and Access) Act 2025 (DUAA), which came into force on 5 February 2026. Under the new regime, organisations no longer need prior consent for cookies used solely for: (1) statistical/analytics purposes (aggregate site-improvement stats only), (2) remembering user appearance preferences, or (3) locating a user for emergency assistance. For the analytics and appearance exemptions, organisations must instead provide a "simple and free means of objecting" -- the ICO clarifies this means a visible, one-step opt-out toggle in the banner itself, not a browser-setting pointer. A fifth pre-existing exemption (strictly necessary) is unchanged. The guidance also broadens scope from cookies to all storage and access technologies (pixels, device fingerprinting, web storage, tag scripts) and adopts prescriptive "must/should/could" language.

ID-PRIVACY IMPACT
---------------------------------------------------------------
Affected subsystems:
  [X] Consent Banner               -- New UK-jurisdiction banner variant needed.
                                      Analytics cookies may now default to ON
                                      (no prior consent required) but a
                                      one-step visible toggle to object must be
                                      present on layer 1, gated by
                                      jurisdiction == UK. Banner must NOT present
                                      a "consent" signal for analytics if the
                                      exemption is used; instead a "no-objection"
                                      signal replaces it. Reject-all button parity
                                      requirement for non-exempt categories is
                                      unchanged.
  [ ] Cookie Classification ML     -- No new categories required; existing
                                      analytics/statistics category covers the
                                      exemption. However, ML must be able to flag
                                      dual-purpose analytics cookies (analytics +
                                      advertising) which do NOT qualify for the
                                      exemption.
  [X] Consent Storage & Proof      -- Proof-of-consent records for analytics
                                      cookies are no longer needed under exemption
                                      path; instead, an opt-out signal (objection
                                      flag) must be stored. Schema must support
                                      "objection" state distinct from
                                      "consent-not-given."
  [X] Consent Signals (GPC/TCF/GPP)-- UK TCF string handling: analytics purpose
                                      under exemption should not be encoded as
                                      "consent = 1"; need to confirm with IAB
                                      Europe whether a TCF-compliant encoding
                                      exists for the UK analytics exemption path.
                                      Potential mis-signal risk if TCF string
                                      incorrectly reflects consent for
                                      analytics under DUAA exemption.
  [X] Geo / Jurisdiction Routing   -- UK ruleset in geolocation engine must be
                                      updated to activate the new analytics-
                                      exemption banner variant for
                                      jurisdiction == UK.
  [ ] Vendor / SDK Governance      -- No new vendor disclosure obligation
                                      introduced by this guidance; existing PECR
                                      third-party disclosure requirements unchanged.
  [ ] DSR Engine                   -- No new DSR rights introduced.
  [X] Audit / Logging              -- Objection records (rather than consent
                                      records) must be stored for analytics under
                                      exemption. Log schema must distinguish
                                      exemption path from consent path.
  [ ] Cross-border transfer        -- Not affected.
  [X] Tenant Config / Admin UI     -- New per-tenant toggle: "Enable DUAA
                                      analytics exemption for UK traffic" (default
                                      OFF; customers must opt in after reviewing
                                      with counsel). When enabled, analytics
                                      category switches from consent-required to
                                      exemption-with-objection-right.
  [X] Documentation / DPIA / RoPA  -- Guidance broadens scope to all storage/
                                      access technologies. RoPA template and
                                      cookie audit outputs should reference "SAT"
                                      not "cookies." Customer-facing DPIA
                                      questionnaire should note the analytics
                                      exemption option.

RISK IF NOT ACTIONED
---------------------------------------------------------------
Risk is LOW-to-MEDIUM. The guidance is interpretive (not a new law); the DUAA
analytics exemption is permissive (organisations may use it but are not required
to). Customers who continue using consent-based analytics remain compliant. The
risk is a missed opportunity for customers to simplify UK analytics consent UX.
The secondary risk is mis-signalling via TCF string if a future customer enables
the exemption without the encoding fix (potential GDPR/PECR violation). PECR
maximum fine is now GBP 17.5 M or 4% global turnover (DUAA-aligned since
2026-02-05). ICO has been actively enforcing cookie banners (99% of top-1000 UK
websites now compliant per ICO).
