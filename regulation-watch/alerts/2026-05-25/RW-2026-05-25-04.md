WHAT CHANGED (plain English)
---------------------------------------------------------------
The CPPA's revised CCPA regulations, effective 1 January 2026,
introduced five engineering-relevant changes beyond prior CCPA/CPRA
rules: (1) Dark patterns prohibition codified in regulation: closing
or navigating away from a consent pop-up without clicking an
affirmative "I accept" button does NOT constitute consent; the
number of opt-out steps must be equal to or fewer than opt-in steps.
(2) GPC opt-out confirmation mandate: businesses must display an
"Opt-Out Request Honored" confirmation message or equivalent
preference-center status indicator after processing a GPC signal --
this is now a mandatory display requirement, not discretionary.
(3) Symmetry requirement: any design that makes the privacy-protective
choice harder, slower, or less visible than the non-protective
alternative is per se prohibited. (4) Cybersecurity audit and risk
assessment regulations took effect with delayed compliance dates
for some sub-provisions. (5) Automated Decision-Making Technology
(ADMT) regulations effective with varying deadlines -- where ADMT
intersects with consent (e.g., consent obtained via algorithmic
personalisation layers), the new rules apply. The CPPA has confirmed
it uses automated scanning tools to detect GPC non-compliance and
dark-pattern violations without waiting for consumer complaints.

---------------------------------------------------------------
ID-PRIVACY IMPACT
---------------------------------------------------------------
Affected subsystems:

  [X] Consent Banner
      (a) Close/dismiss button on consent pop-ups must not be
      treated as consent under CA jurisdiction. The banner must
      require affirmative button click for consent to be recorded.
      Any consent flow that records consent on overlay-click-away
      or page-scroll must be disabled for CA.
      (b) The opt-out flow (DNSS/share link or preference center)
      must have equal or fewer steps than the opt-in flow. If
      opt-in is 1 click, opt-out must also be achievable in 1 click.
      (c) Visual symmetry: "Accept All" and "Reject All" / "Opt Out"
      buttons must have equivalent visual weight (size, color, font)
      for CA-jurisdiction visitors.

  [ ] Cookie Classification ML
      No direct change.

  [X] Consent Storage & Proof
      Consent records must reflect that consent was obtained via
      affirmative button click (not implied). Add a consent_method
      field with value: affirmative_click (required for CA) vs.
      implied (must not be used for CA consent records).

  [X] Consent Signals (GPC/TCF/GPP)
      GPC signal handling now requires a visual confirmation display.
      When a GPC signal is detected for a CA visitor, the platform
      must display "Opt-Out Request Honored" (or equivalent status)
      to the user. This must be rendered in the banner / preference
      center UI -- not just logged silently. Current behavior (silent
      GPC processing) is non-compliant with the 1 Jan 2026 rules.
      Priority fix required.

  [X] Geo / Jurisdiction Routing
      CA jurisdiction ruleset must enforce: (a) no implied consent,
      (b) step-symmetry validation (automated check that opt-out
      step count is <= opt-in step count), (c) GPC confirmation
      display.

  [ ] Vendor / SDK Governance
      No new vendor-specific requirement. Existing CCPA opt-out
      chain (passing GPC to downstream vendors) unchanged.

  [ ] DSR Engine
      No new rights introduced by these regulations.

  [X] Audit / Logging
      Consent records for CA must log consent_method=affirmative_click
      and must log GPC signals received plus the confirmation
      displayed. The CPPA uses automated tools to audit GPC
      compliance; platform audit logs must be producible as evidence.

  [ ] Cross-border transfer
      No new transfer mechanism.

  [X] Tenant Config / Admin UI
      Banner configuration for CA must surface a validation warning
      if: (a) dismiss/close is mapped to consent, (b) opt-out steps
      exceed opt-in steps, (c) GPC confirmation display is disabled.
      Add a CA compliance check in the tenant banner health dashboard.

  [ ] Documentation / DPIA / RoPA
      Minor update: note that CCPA consent requires affirmative click
      and document GPC confirmation obligation.
