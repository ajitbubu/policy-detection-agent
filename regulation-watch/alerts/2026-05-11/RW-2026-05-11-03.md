WHAT CHANGED
---------------------------------------------------------------
Prior rule: businesses subject to CCPA/CPRA had to honor opt-out requests
(including GPC signals) but had no specific obligation to visibly confirm
that an opt-out had been processed. Closing or navigating away from a consent
pop-up was an ambiguous signal with no regulatory clarity.

New rule (effective 2026-01-01, three consent-banner-specific obligations):
(1) Opt-out confirmation is now mandatory: when a California consumer has
opted out of the sale/sharing of their personal information — including via
a GPC signal — the business must provide a visible confirmation mechanism,
such as displaying "Opt-Out Request Honored" or toggling a control in the
user's privacy settings to reflect opted-out status. This applies to both
explicit requests and automatic GPC signal processing.
(2) Pop-up closure is not consent: a consumer closing or navigating away
from a consent request pop-up without affirmatively selecting "I accept" (or
equivalent) does not constitute consent. CMPs that treat banner dismissal as
implied consent or that fire tags on page-unload/close are now explicitly
non-compliant.
(3) Dark-pattern symmetry codified: the path to deny or withdraw consent may
require no more steps than the path to grant consent. One-click accept versus
multi-click reject is now a defined violation (codified after Honda-CPPA
settlement precedent).

---------------------------------------------------------------
WHO IS AFFECTED
---------------------------------------------------------------
Applicability test:  Controllers that collect personal information from
                     California consumers and meet the CCPA thresholds
                     (>$25M revenue; OR process 100,000+ consumers/households
                     annually; OR derive 50%+ revenue from selling/sharing
                     personal data). Applies to the controller — but CMP
                     vendors are their agents and the CMP's behavior is
                     attributable to the controller.
DataSafeguard customers likely affected:  All US-market tenants serving
                     California traffic. Tenants operating as data brokers
                     or ad-tech businesses face highest immediate exposure.
                     Estimated: the majority of enterprise-tier US tenants.
Customer notice required:  YES — within 30 days (by 2026-06-10). Tenants
                     need to know whether their banner configurations are
                     generating the opt-out confirmation signal and whether
                     their pop-up dismissal behavior is now compliant.

ID-PRIVACY® IMPACT
---------------------------------------------------------------
Affected subsystems:
  [X] Consent Banner               Three concrete UI/UX changes required for
                                   California route: (a) add an "Opt-Out
                                   Request Honored" confirmation state or
                                   equivalent visual confirmation that fires
                                   on detection of a GPC signal or completed
                                   opt-out request; (b) ensure that banner
                                   dismissal (ESC key, X button, click-
                                   outside) does NOT trigger a "consent
                                   granted" event or fire any non-essential
                                   tags; (c) enforce step-parity between
                                   accept and reject paths — reject-all must
                                   be reachable in the same number of clicks
                                   as accept-all on the California banner.
  [ ] Cookie Classification ML     Not directly affected.
  [X] Consent Storage & Proof      Consent records for California users must
                                   now include the opt-out confirmation event:
                                   timestamp, method (GPC auto / user explicit
                                   request), and the displayed confirmation
                                   state. Absence of this record is evidence
                                   of non-compliance in an enforcement inquiry.
  [X] Consent Signals (GPC/TCF/GPP) GPC signal detection must now trigger a
                                   visible opt-out confirmation in addition to
                                   the existing "honor the signal" behavior.
                                   The confirmation must be displayed to the
                                   user, not merely logged server-side. GPP
                                   string for California (US National Privacy
                                   spec section 8) should reflect the opted-
                                   out state; confirm the string update is
                                   written after GPC detection, not before.
  [X] Geo / Jurisdiction Routing   California-specific banner variant must
                                   be deployed for these changes. Ensure the
                                   CA-geo rule is not inadvertently applied
                                   to other US states that do not yet have
                                   the same confirmation obligation.
  [ ] Vendor / SDK Governance      Not directly affected by this change.
  [X] Audit / Logging              Log: (a) whether a GPC signal was detected
                                   per session; (b) whether opt-out
                                   confirmation was displayed; (c) which
                                   method of opt-out was used. This is the
                                   evidence chain the CPPA would request in
                                   an enforcement action.
  [ ] Cross-border transfer        Not directly affected.
  [X] Tenant Config / Admin UI     Tenant should be able to configure the
                                   opt-out confirmation message text; toggle
                                   the confirmation widget style (badge,
                                   toggle, inline message); review a GPC-
                                   detection rate report. Admin UI should
                                   flag if a CA-gated banner has dismiss-as-
                                   consent behavior enabled.
  [X] Documentation / DPIA / RoPA  Update California compliance guide to
                                   include the three new banner obligations.
                                   Update DPIA template to document GPC
                                   confirmation implementation.

RECOMMENDED ACTIONS
---------------------------------------------------------------
ENGINEERING (Abhishek's track):
  1. Banner dismissal guard: audit all California-routed banner close/dismiss
     event handlers. Confirm none fires a consent-granted event, a pixel,
     or a tag-release on dismissal without explicit user acceptance.
     Est. 3 pts (audit) + 3 pts (fix) — by 2026-05-25.
  2. Opt-out confirmation widget: implement a visible confirmation state for
     the CA banner route that renders when GPC is detected or an explicit
     opt-out request is completed. Minimum: a badge or inline message reading
     "Opt-Out Request Honored" (or tenant-configurable equivalent). This must
     persist for a reasonable session duration (not flash and disappear).
     Est. 5 pts — by 2026-06-01.
  3. GPC signal pipeline: confirm that GPC detection (navigator.globalPrivacyControl
     == true) triggers: (a) opt-out event recorded in consent storage, (b)
     confirmation widget rendered on page, (c) GPP string updated to reflect
     CA opted-out state. If GPC detection is currently server-side only,
     add a client-side check to drive the confirmation UI.
     Est. 5 pts — by 2026-06-01.
  4. Step-parity audit: map the click-path for "Accept All" vs. "Reject All"
     on the California banner variant. If accept-all is 1 click and reject-
     all requires navigating to preferences, this is a violation. Implement
     a "Reject All" button on the first layer of the CA banner.
     Est. 3 pts — by 2026-05-25.
  5. Consent-event log: add fields for "gpcDetected" (bool),
     "optOutConfirmationDisplayed" (bool, timestamp), and "optOutMethod"
     (enum: gpc | explicit_request | banner_reject) per California session.
     Est. 2 pts — by 2026-06-01.
  6. Admin UI: add a "CA GPC compliance" dashboard panel showing GPC
     detection rate, confirmation display rate, and banner dismiss events
     that did NOT result in consent grant. Flag configurations with
     dismiss-as-consent behavior. Est. 5 pts — by 2026-06-15.

RISK IF NOT ACTIONED
---------------------------------------------------------------
CPPA fines run up to $7,988 per intentional violation and $2,663 per
unintentional violation (indexed from 2025; adjusted annually). The CPPA/CO/CT
joint GPC sweep announced September 2025 means enforcement letters to specific
businesses are likely already in-flight. A business receiving a CPPA notice
whose banner dismissal behavior constituted "consent" — or whose GPC-detected
users see no confirmation — faces immediate financial exposure. A single high-
volume publisher tenant with millions of California visitors could face tens of
millions in aggregate fines. Reputational harm to DataSafeguard if a tenant
is publicly cited as non-compliant while using ID-PRIVACY.
