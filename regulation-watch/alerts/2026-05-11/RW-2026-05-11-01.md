---------------------------------------------------------------
WHAT CHANGED
---------------------------------------------------------------
Prior rule (TCF v2.2): the "disclosedVendors" segment of the TC string was
optional. Vendors had to infer from the TC string whether they were actually
surfaced to the user, creating an ambiguity that some vendors exploited to
claim Special Purpose processing rights without being disclosed.

New rule (TCF v2.3, mandatory from 28 February 2026): the disclosedVendors
segment is mandatory in every TC string generated by a registered CMP on or
after 28 February 2026. The segment uses a binary bit per vendor ID (1 =
disclosed to user; 0 = not disclosed). TC strings created after the deadline
that omit the disclosedVendors segment are spec-invalid. Downstream vendors
must check their Vendor ID bit in the segment before asserting Special
Purposes; absence of the segment means they cannot assert Special Purpose
processing. The practical consequence is that every ad call using a non-
compliant string is treated as "Limited Ads" (contextual only), collapsing
CPMs and programmatic revenue for affected publisher-tenants.
