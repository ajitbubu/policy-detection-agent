WHAT CHANGED (status update — promotion from baseline LOW)
---------------------------------------------------------------
Since the baseline was recorded on 2026-05-09, the EU Digital Omnibus
legislative process has advanced materially: the Council of the EU adopted its
negotiating mandate on 2026-03-13, the European Parliament's IMCO/LIBE
committees' text was adopted in plenary on 2026-03-26, and the second political
trilogue was held on 2026-04-28 without final agreement. A third trilogue is
scheduled for 2026-05-13 -- within the next four days from this scan. The
baseline carried this item as LOW ("pre-binding; promote to MEDIUM if Digital
Omnibus reaches a Council general approach"). That trigger has now been met.
The proposal, if adopted, would: (1) move cookie/tracking consent rules from
the ePrivacy Directive into the GDPR via new Articles 88a and 88b; (2) require
a one-click reject mechanism; (3) establish a 6-month cooldown before re-
requesting consent for the same purpose; (4) create new low-risk cookie
exemptions (analytics-only, appearance); and (5) mandate that controllers
support machine-readable browser preference signals (Art. 88b) within 24
months of entry into force.

ID-PRIVACY IMPACT
---------------------------------------------------------------
Affected subsystems (anticipated -- subject to final text):
  [X] Consent Banner               -- Art. 88a: one-click reject button must be
                                       present with equal prominence to accept;
                                       6-month cooldown on re-prompting after
                                       rejection. If current EU banner does not
                                       already have a layer-1 "Reject All"
                                       with parity styling and a 6-month re-
                                       prompt suppression timer, this will be
                                       a required change. (Note: CNIL and
                                       Garante already enforce functionally
                                       equivalent rules via GDPR; the Omnibus
                                       codifies EU-wide.)
  [ ] Cookie Classification ML     -- New low-risk exemption categories (analytics-
                                       only, appearance) closely mirror DUAA (UK).
                                       EU classifier will need the same single-
                                       purpose purity test as UK track.
  [X] Consent Storage & Proof      -- 6-month cooldown requires a stored timestamp
                                       of last rejection per user per purpose.
                                       Consent storage schema must accommodate
                                       `last_rejected_at` and `cooldown_expires`
                                       fields per purpose category.
  [X] Consent Signals (GPC/TCF/GPP)-- Art. 88b: controllers must support
                                       machine-readable browser preference
                                       signals. This is a mandatory GPC/browser-
                                       signal API obligation for EU, not just a
                                       US state law. Timeline is 24 months post
                                       entry-into-force, but architecture
                                       decisions should start now.
  [X] Geo / Jurisdiction Routing   -- EU cookie exemptions (analytics, appearance)
                                       will need their own ruleset, distinct
                                       from current ePrivacy-derived ruleset.
                                       Must avoid premature deployment before
                                       law enters force.
  [ ] Vendor / SDK Governance      -- No structural change anticipated.
  [ ] DSR Engine                   -- No direct impact.
  [X] Audit / Logging              -- Cooldown period enforcement requires
                                       durable per-user rejection logs with
                                       timestamps. Existing consent-storage
                                       layer may not retain rejection events
                                       as durably as consent grants.
  [ ] Cross-border transfer        -- No direct change from cookies provisions.
  [X] Tenant Config / Admin UI     -- New Art. 88a exemption toggles needed
                                       (parallel to UK DUAA work); 6-month
                                       cooldown configuration.
  [X] Documentation / DPIA / RoPA  -- DPIA templates for EU customers will need
                                       updating when law enters force.
