# Proposed Monitoring Source List
**Run date:** 2026-05-09
**For:** Director of Engineering, DataSafeguard

---

## Preamble

URLs below are **link-verified by reference** (i.e., reported by reputable secondary sources and consistent with the publishers' canonical domains). **WebFetch was blocked (HTTP 403) for several official domains in this run**, so direct fetch verification was not possible across the board. Engineering should confirm each URL before wiring it into a scraper / RSS reader / feed monitor.

Tier definitions follow the operating prompt:
- **Tier 1** — High-impact; weekly minimum, Tier-1 daily Mon–Fri scan target.
- **Tier 2** — Lower frequency / regional; monthly.
- **Tier 3** — Watch list / framework / industry; light monthly scan.

"Primary" = canonical regulator / legislature / framework publisher.
"Secondary" = trackers used to surface what to read; click through to primary before alerting.

## Notes / open items for the Director of Engineering

1. **DPB India URL not yet stable.** Once the Data Protection Board of India publishes a canonical site, swap the placeholder in Tier 1.
2. **WebFetch blocked.** If we want fetch-based monitoring rather than human-driven scans, we will need an authenticated/headed scraper (or an MCP fetch server) for several official domains; flagging as a pre-requisite for true automated cadence.
3. **RSS / Atom feeds.** Many regulators expose RSS (EDPB, ICO, CNIL, FTC); these are cheaper than polling HTML and should be preferred when available.
4. **Tier 1 daily scope.** Realistically, daily scope should be ~6–10 sources (CPPA, CNIL, ICO, EDPB news, FTC, MeitY, ANPD, IAPP Daily Dashboard, plus the active state AG pages with pending action). The full Tier 1 list above is the **weekly** universe.
5. **Suggested kill-criteria.** A source that has produced zero relevant items in 12 months should be downgraded one tier; conversely, a Tier 2/3 source that produces ≥2 in-scope items in a quarter should be promoted.
